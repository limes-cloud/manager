# IP 获取 (library/ip)

> 包路径：`github.com/limes-cloud/kratosx/library/ip`

## 概述

从请求中提取客户端真实 IP 地址，支持 gRPC 和 HTTP 两种协议。

## 获取逻辑

1. **gRPC**：从 `peer.FromContext` 获取远端地址
2. **HTTP**：优先从 `x-real-ip` Header 获取，回退到 `RemoteAddr`
3. `::1` 自动转为 `localhost`

## 使用方式

```go
// 通过 Context 获取
ip := ctx.ClientIP()
// 返回如："192.168.1.100" 或 "localhost"
```

## 注意

- 在反向代理（Nginx）后面部署时，确保配置了 `proxy_set_header X-Real-IP $remote_addr;`
- IP 中间件在中间件链中自动执行，无需手动配置
